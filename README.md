# bar-novel-bootstrap

BAR NOVEL（伊勢原のバー）のホームページ。
元リポジトリ `sota-furuta/bar-novel` の **feature-bar-novel-oner-review ブランチをベース**に、
Bootstrap 5.3.8 で UI を刷新した版です（PC・スマホ両対応）。

## ベース（oner-review）から引き継いだもの
- 色: 背景ゴールドグラデーション / 差し色 #e0b06a / 濃色 #0b0a08 / クリーム #f2e3c6 / 枠 #5a3a1d
- ヒーローのコピー「女性一人でも気軽に。会話とお酒を楽しむ居心地の良い空間。」と全面写真
- 詳細メニュー（カクテル ¥750〜、ソーセージ盛り合わせ ¥1,000 など）、店舗情報、写真・キャプション

## UI 刷新点
- PC: メニューは DRINK / FOOD の2カラムカード、情報とアクセスを横並び、ギャラリーはグリッド＋モーダル拡大
- 共通: ナビにページ内リンク＋スクロールスパイ、ヒーローに営業バッジと Maps ボタン、
  スクロールでふわっと表示、電話はタップ発信
- スマホ: ハンバーガーメニュー、下部固定バー（電話／地図／Instagram）、
  ギャラリー2カラム、ボタンは横幅いっぱいに押しやすく

## 画像
元リポジトリの images/（exterior / interior / pasta / food）を raw URL でリンク表示し、
